# Resumo do Projeto

O **Projeto Neo Sus** é uma proposta de reformulação completa da experiência digital do Sistema Único de Saúde, com foco em acessibilidade, inclusão digital, design humanizado e modernização tecnológica.

O projeto busca criar uma plataforma moderna, intuitiva e acessível para toda a população brasileira, incluindo:
- idosos
- pessoas com deficiência
- usuários com baixa alfabetização
- pessoas com dificuldade de navegação digital

A proposta utiliza conceitos modernos de:
- UX/UI Design
- Mobile First
- Acessibilidade Digital
- Engenharia de Software
- Design Systems
- Arquitetura Escalável

---

# Objetivos do Projeto

## Objetivo Geral

Desenvolver uma plataforma digital moderna e acessível para o SUS, melhorando a experiência dos usuários e facilitando o acesso aos serviços públicos de saúde.

---

## Objetivos Específicos

- Modernizar a interface do SUS
- Melhorar a acessibilidade digital
- Reduzir dificuldades de navegação
- Facilitar o acesso aos serviços médicos
- Humanizar a experiência do usuário
- Melhorar a experiência mobile
- Incluir suporte para usuários analfabetos
- Implementar suporte completo em LIBRAS
- Criar um sistema intuitivo e responsivo

---

# Problemas Identificados

Foram identificados diversos problemas nas plataformas públicas de saúde atuais:

- Interfaces confusas
- Navegação complexa
- Baixa acessibilidade
- Dificuldade para idosos
- Pouca responsividade mobile
- Falta de suporte inclusivo
- Excesso de burocracia digital
- Dificuldade de acesso rápido às informações
- Falta de humanização visual
- Sistemas pouco intuitivos

---

# Solução Proposta

A solução consiste em um redesign completo da plataforma do SUS utilizando princípios modernos de desenvolvimento de software e experiência do usuário.

O sistema será reconstruído com foco em:
- simplicidade
- acessibilidade
- performance
- inclusão digital
- design humanizado
- usabilidade

# Diferenciais do Projeto

## Design Humanizado

O projeto utiliza uma abordagem focada na experiência emocional do usuário, reduzindo ansiedade e dificuldades durante a navegação.

---

## Acessibilidade Avançada

A plataforma foi projetada para atender:
- idosos
- pessoas com deficiência
- usuários com baixa alfabetização
- usuários com pouca experiência digital

---

## Mobile First

Toda a experiência é otimizada para dispositivos móveis, considerando usuários com:
- internet limitada
- aparelhos simples
- baixa performance
